
# CombatFX-Lite

**A lightweight combat feedback system for Unreal Engine 5, built entirely with Blueprints.**

CombatFX-Lite is a small combat feedback project designed to demonstrate and provide essential combat mechanics for Unreal Engine 5 projects.

The project focuses on implementing basic combat interactions and visual feedback while keeping the setup accessible to developers who work primarily with Blueprints.

Whether you are learning Unreal Engine or prototyping a combat system, CombatFX-Lite provides a starting point for experimenting with combat mechanics and player feedback.

## Project Overview

- **Engine:** Unreal Engine 5
- **Implementation:** Blueprint Visual Scripting
- **Project Type:** Combat Feedback System
- **Version:** Lite
- **Target Audience:** Unreal Engine developers and beginners


## What We Plan to Improve in Future Projects

CombatFX-Lite is also part of our development and learning journey.

For future projects, our main goal is to improve the overall architecture, modularity, scalability, and code organization.

Our priorities include:

- **100% Modular Architecture:** Design systems as independent and reusable components.
- **Better Blueprint Organization:** Improve readability, naming conventions, and overall structure.
- **Scalability:** Make systems easier to extend and integrate into different projects.
- **Improved Documentation:** Provide clearer explanations and implementation guides.
- **Better Development Practices:** Focus on maintainability, flexibility, and cleaner architecture.

Our goal is to make each new project better structured, more modular, and more polished than the previous one.
